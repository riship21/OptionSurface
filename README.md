# OptionSurface

Interactive 3D Options Volatility Surface Explorer.

OptionSurface is a WebGL2 application for visualizing options implied volatility across strike price and time to expiration.

## Technology

- WebGL2
- JavaScript
- GLSL ES 3.00
- gl-matrix
